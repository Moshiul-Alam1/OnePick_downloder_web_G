ধাপ ১: vercel.json ফাইলটি আপডেট করো
তোমার GitHub-এর vercel.json ফাইলটি খুলে পুরো কোডটি বদলে নিচের কোডটি দিয়ে আপডেট (Commit) করে দাও:

JSON
{
  "version": 2,
  "builds": [
    {
      "src": "index.html",
      "use": "@vercel/static"
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/index.html"
    }
  ]
}
এটি কী করবে? "use": "@vercel/static" লাইনটি Vercel-কে বাধ্য করবে Python না চালিয়ে সরাসরি তোমার index.html ওয়েবসাইটটি ব্রাউজারে ডিসপ্লে করতে।
